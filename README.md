# IT Career Atlas

A visual, interactive knowledge website designed to help beginners explore the world of IT careers.

IT Career Atlas organizes IT roles into major career chapters, branches, required skills, technologies, tools, AI involvement, learning paths, projects, and job-readiness guidance.

## 🎯 Concept

The website uses two directions of exploration:

**Horizontal Swipe → Explore different IT roles**

**Vertical Scroll ↓ → Explore chapters within a role**

```text
🏠 Home
   │
   ├── Swipe → 01 Designer
   │              │
   │              ├── 01.1 What is a Designer?
   │              ├── 01.2 What do they do?
   │              ├── 01.3 Branches
   │              ├── 01.4 Required Skills
   │              ├── 01.5 Tools & Technology
   │              ├── 01.6 AI / Manual / Hybrid
   │              ├── 01.7 Learning Roadmap
   │              └── 01.8 Job Readiness
   │
   └── Swipe → 02 Developer
                  │
                  ├── 02.1 What is a Developer?
                  ├── 02.2 Main Branches
                  ├── 02.3 Frontend → React
                  ├── 02.4 Backend
                  ├── 02.5 AI / Manual / Hybrid
                  ├── 02.6 Learning Roadmap
                  └── 02.7 Job Readiness
✨ UX Philosophy
The interface is inspired by natural, gesture-based mobile experiences.
📱 Touch-first interaction
👈👉 Horizontal swipe between major roles
👇 Vertical scrolling through role chapters
✨ Smooth transitions between roles
↓ Subtle scroll indicators
🚫 No intrusive tutorials
🚫 No permanent navigation arrows
💻 Trackpad and keyboard support for desktop
The goal is to let users discover the navigation naturally through interaction.

🤖 AI Integration
A major part of the project is explaining how AI fits into modern IT careers.
Each role can identify work as:
Mode
Meaning
🤖 AI
AI can perform or strongly assist the task
👤 Manual
Primarily requires human execution
🔄 Hybrid
Human + AI working together
The goal is to help users understand not only what technologies are required, but also how professionals can work with AI.
